# 貢献について / Contributing

## 日本語

- 不具合の報告・質問・提案は、**Issue** でお寄せください。歓迎します。
  不具合のときは、OS・版・手順と、できれば問題の出るファイル（またはその作り方）を添えてください。
- このリポジトリのコードは、著作権者が別の条件（再生器 Vuecove）でも使っているため、**プルリクエストは受け付けていません**。
- セキュリティの問題など、公開の場で扱うのがふさわしくない内容は、https://www.aaiw.net/contact/ からお知らせください。

## English

- Bug reports, questions and suggestions are welcome as **Issues**. For bugs, please include your OS, the version, the
  steps, and if possible the file that shows the problem (or how to make it).
- The code in this repository is also used by the copyright holder under different terms (the Vuecove player), so
  **pull requests are not accepted**.
- For security issues or other matters that should not be discussed in public, please use https://www.aaiw.net/contact/.
